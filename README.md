# ❄️ Winter Arc

A full-stack habit and productivity tracker designed to help users build consistency, manage daily tasks, track progress, and maintain productive routines.

## 🚀 Features

- 🔐 User Registration & Login
- 🔒 JWT-based Authentication
- 🎯 Habit Management
- ✅ Daily Habit Completion Tracking
- 📝 To-Do Task Management
- 📅 Calendar-based History
- 📊 Productivity Statistics
- 🔥 Current & Best Streak Tracking
- 👤 User Profile
- ☁️ MongoDB Cloud Storage
- 📱 Responsive UI

## 🛠️ Tech Stack
